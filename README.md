# 🐍 Snake Game

> A fully functional snake game built with JavaScript, optimized for desktop and laptop use.

🔗 Live Demo: https://huzaifasnakegame.netlify.app/  
🔗 GitHub Repo: https://github.com/HuzaiFaRz/Snake-Game  

---

## 📌 Project Overview

This project recreates the classic snake game where the player controls a snake to collect items while avoiding collisions with walls and itself.

---

## ✨ Features

- Full snake movement controls
- Item collection logic
- Collision detection
- Score tracking
- Desktop & laptop optimized

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🎯 Learning Outcomes

- Game logic implementation
- DOM manipulation for game rendering
- Event handling for keyboard input
- Real-time state management
